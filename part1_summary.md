## Dataset Details

**Source:** Kaggle Cardiovascular Disease Dataset  
**Original Size:** 70,000 patient records  
**After Cleaning:** 65,439 records (removed 6.5% with physiologically implausible values)  
**Class Balance:** Perfect 50/50 (CVD present vs absent)  
**Train/Test Split:** 80/20 stratified (52,351 train / 13,088 test)

### Features (11 total):
1. **age_years** - Age in years (converted from days)
2. **gender** - 1=female, 2=male
3. **height** - Height in cm
4. **weight** - Weight in kg
5. **bmi** - Body Mass Index (engineered feature: weight/(height/100)²)
6. **ap_hi** - Systolic blood pressure
7. **ap_lo** - Diastolic blood pressure
8. **cholesterol** - 1=normal, 2=above normal, 3=well above normal
9. **gluc** - Glucose level: 1=normal, 2=above normal, 3=well above normal
10. **smoke** - Smoking status: 0=no, 1=yes
11. **alco** - Alcohol intake: 0=no, 1=yes
12. **active** - Physical activity: 0=no, 1=yes

**Target:** cardio (0=No CVD, 1=CVD present)

## Pipeline Implementation

### Step 1: Data Preprocessing (`src/data_preprocessing.py`)
**Functions:**
- `load_data()` - Load cardio_train.csv
- `engineer_features()` - Convert age to years, calculate BMI
- `remove_outliers()` - Remove physiologically implausible values:
  - Systolic BP: 80-220 mmHg
  - Diastolic BP: 50-140 mmHg
  - Height: 130-230 cm
  - Weight: 30-200 kg
- `prepare_features_target()` - Separate X and y
- `split_data()` - 80/20 stratified split

**Output:** X_train.csv, X_test.csv, y_train.csv, y_test.csv

### Step 2: Model Training (`src/model_training.py`)
**Functions:**
- `apply_transformations()` - Create original/standardized/minmax versions
- `train_logistic_regression()` - C=1.0, max_iter=1000, solver='lbfgs'
- `train_svm()` - kernel='rbf', C=1.0, gamma='scale', probability=True
- `train_neural_network()` - layers=(64,32), activation='relu', optimizer='adam'

**Output:** 6 .pkl model files

### Step 3: Evaluation (`src/evaluation.py`)
**Metrics Calculated:**
- Accuracy
- Precision
- Recall
- F1-Score
- AUC-ROC (primary metric)

**Output:** model_results.csv

## Key Technical Insights

### Why Transformations Matter:

**For SVM:**
- RBF kernel uses Euclidean distance: K(x,x') = exp(-γ||x-x'||²)
- Without standardization, BP (range 80-220) dominates smoking (0-1) by 220x
- Distance calculation example:
```
  Original: (120-180)² + (0-1)² = 3600 + 1 = 3601 (BP is 99.97%)
  Standardized: (0.2-1.8)² + (-0.8-1.2)² = 2.56 + 4.0 = 6.56 (balanced)
```

**For Logistic Regression:**
- Theoretically scale-invariant (adjusts weights)
- Small improvement from better numerical stability

**For Neural Networks:**
- Helps gradient descent convergence
- Keeps activations in effective range
- Prevents numerical instability
